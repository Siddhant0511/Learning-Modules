Variables in Research
Understanding the different types of variables is the foundation of all hypothesis testing and research design.
IV
Independent Variable
The variable you manipulate or control to see its effect. The "cause" in cause-effect.

Examples: Platform type (App vs Website), Type of detergent, Gender, Tenure, AR vs Non-AR media
DV
Dependent Variable
The variable being measured/observed. The "effect" or outcome. Changes in response to the IV.

Examples: Usefulness score, Whiteness meter reading, Motivation, Willingness to Pay Premium
CV
Control Variable
Variables held constant so they don't confound results. Deliberately managed by the researcher.

Examples: Age group, Device type, Prior brand loyalty, Income level, Frequency of app use
EV
Extraneous Variable
Uncontrolled factors that could affect the DV but aren't the focus. If not managed, become confounding variables.

Examples: Mood of respondent, Time of day, Noise in environment
MED
Mediating Variable
Explains HOW or WHY the IV affects the DV. It is both an outcome of IV and a cause of DV (the mechanism in the middle).

Example: IV=Holacracy → Med=Employee Satisfaction → DV=Motivation
IV → Mediator → DV
MOD
Moderating Variable
Changes the strength or direction of the IV→DV relationship. It's an interaction variable.

Example: Gender moderates effect of AR on purchase intent (AR works differently for males vs females)
IV × Moderator → DV
Mediator vs Moderator — Quick Memory Trick:
Mediator = the middle man (explains the process). Moderator = the modifier (changes the strength/direction). Mediation answers "how?", Moderation answers "when?" or "for whom?"

Types of Data / Measurement Scales

NOMINAL
Categories with no order. Examples: Gender (M/F), Platform (App/Website), AR/NonAR. Use: Frequency, Cross-Tabulation.
ORDINAL
Ranked categories, unequal gaps. Examples: Likert scale (1-5), Tenure categories. Use: Median, Non-parametric tests.
INTERVAL
Equal gaps, no true zero. Examples: Temperature (°C), Likert treated as interval in SPSS. Use: T-tests, ANOVA.
RATIO
Equal gaps + true zero. Examples: Sales revenue, Age in years, Distance. Use: All parametric tests, Regression.

Hypothesis Structure

H₀ (Null Hypothesis): Assumes NO effect, NO difference, NO relationship. Always contains = (or ≤ or ≥).
H₁ / Hₐ (Alternate Hypothesis): The research claim. Contains ≠ (two-tailed) or > or < (one-tailed).
H₀: μ₁ = μ₂ (no significant difference between groups) H₁: μ₁ ≠ μ₂ (there is a significant difference) ← Two-tailed H₀: μ ≤ 3 (mean is not greater than 3) H₁: μ > 3 ← One-tailed (directional) Decision Rule: If p-value < α (0.05) → Reject H₀ If p-value ≥ α (0.05) → Fail to Reject H₀

Sampling Plan — 5 Steps

  1. Define the Population: Who is your target? (e.g., all iQMetrix employees who experienced Holacracy)
  2. Determine the Sampling Frame: The actual list you'll draw from (e.g., employee database where Holacracy was rolled out)
  3. Select Sampling Technique: Probability (Simple Random, Stratified, Cluster) or Non-Probability (Convenience, Purposive, Snowball)
  4. Determine Sample Size: Based on population size, margin of error, confidence level (typically use formula or rule of thumb: N ≥ 100 for t-tests, N ≥ 200 for SEM/Factor Analysis)
  5. Execute the Sampling Process: Distribute questionnaires, collect data systematically

Research Design Types

Experimental Design: Researcher manipulates IV. Has treatment and control groups. Best for establishing causality. Used in Adidas AR experiment, Detergent study.
Survey/Descriptive Design: No manipulation. Measures variables as they exist. Used in iQMetrix Holacracy study (questionnaire-based).
Factorial Design: Tests multiple IVs and their interactions simultaneously. E.g., 2×2 design = 2 levels of IV1 × 2 levels of IV2. Used in Two-Way ANOVA (Detergent × Temperature, AUGTARGET × Mediatype).
Cross-Sectional: Data collected at one point in time. Vs Longitudinal: multiple time points. Most MBA exam cases use cross-sectional data.

Frequency Analysis

Purpose: Understand how data is distributed across categories of a single variable. Produces count and percentage for each value.

When to Use

Profile your sample. First step in any analysis. Use for nominal/ordinal variables like Gender, Age bracket, Tenure, Platform type.

No Hypothesis Needed

Frequency is purely descriptive — no hypothesis testing involved. Results show frequencies, valid %, cumulative %.

Key Output Fields

Frequency = Count of cases in each category Valid Percent = % excluding missing values Cumulative Percent = Running total of valid %
SPSS Path: Analyze → Descriptive Statistics → Frequencies

Cross-Tabulation (Chi-Square)

Purpose: Examine the relationship/association between two categorical variables. Answers: "Does one category variable depend on another?"

When to Use

Both variables are nominal/ordinal. E.g., Is AR usage associated with gender? Does platform preference depend on age group?

Hypothesis

H₀: There is no association between Variable A and Variable B H₁: There is a significant association between Variable A and Variable B Decision: If p (Asymp. Sig) < 0.05 → Reject H₀

Key Check — Assumptions

  • Expected cell count ≥ 5 in at least 80% of cells (else use Fisher's Exact Test)
  • Cramer's V or Phi tells you strength of association (0–1)
SPSS Path: Analyze → Descriptive Statistics → Crosstabs → Statistics → Chi-Square

One Sample T-Test

Purpose: Compare the mean of ONE group to a known/hypothesized population value (test value). E.g., Is mean satisfaction > 3 (midpoint)?

When to Use

One group, one continuous DV, comparing to a benchmark value. Common with Likert scales: "Is usefulness rated significantly above neutral (3)?"

Hypothesis (Example: Is Hol_Imp > 3?)

H₀: μ ≤ 3 (Holacracy satisfaction is not greater than 3) H₁: μ > 3 (Holacracy satisfaction is greater than 3) ← One-tailed Test Value = 3 (entered in SPSS) Decision: If p < 0.05 → Reject H₀ → Mean is significantly > 3

Key Output

  • t value: test statistic
  • df: n - 1
  • Sig (2-tailed): Divide by 2 for one-tailed
  • Mean Difference: Sample mean minus test value
  • 95% CI: Confidence interval around the difference
SPSS Path: Analyze → Compare Means → One-Sample T Test → enter Test Value

Independent Samples T-Test

Purpose: Compare means of TWO INDEPENDENT groups on a continuous DV. "Do these two different groups differ in their average score?"

When to Use

Two groups of different people: App vs Website users, Males vs Females, AR vs Non-AR users. DV must be continuous (interval/ratio).

Hypothesis (Example: App vs Website Usefulness)

H₀: μ(App) = μ(Website) → No significant difference in usefulness H₁: μ(App) ≠ μ(Website) → There is a significant difference (two-tailed) Decision: If p < 0.05 → Reject H₀ → Groups differ significantly

Critical Rule — Levene's Test

ALWAYS check Levene's Test first before reading t-test results!
Levene's p > 0.05 → Use "Equal variances assumed" row
Levene's p ≤ 0.05 → Use "Equal variances NOT assumed" row

Key Output

Levene's F & SigTests if variances are equal. Tells you which row to use.

dfDegrees of freedom
Sig. (2-tailed)p-value. Compare to 0.05.

Paired Samples T-Test

Purpose: Compare two measurements from the SAME subjects/respondents. Pre-test vs post-test, or two related variables (HOL_IMP vs STAY for same employee).

When to Use

Same respondents measured twice (before/after intervention), or comparing two related variables from the same person. E.g., "Does Holacracy satisfaction predict stay intentions?" can also be examined via paired t-test when both are measured on same person and you want to compare their mean levels.

Hypothesis

H₀: μ(difference) = 0 → No significant difference between paired measures H₁: μ(difference) ≠ 0 → Significant difference exists Decision: If p < 0.05 → Reject H₀

Key Output

  • Paired Differences Mean: Average of (score1 - score2)
  • t value, Sig (2-tailed): Same interpretation as independent t-test
  • 95% CI: If it doesn't cross 0 → significant difference
SPSS Path: Analyze → Compare Means → Paired-Samples T Test

One-Way ANOVA

Purpose: Compare means of 3 or more independent groups on a continuous DV. Extension of independent t-test for more than 2 groups.

When to Use

One nominal IV with 3+ categories. E.g., Does Holacracy satisfaction differ across 8 tenure groups? Does motivation differ across 3 age brackets?

Hypothesis (Example: Tenure vs Hol_Imp)

H₀: μ₁ = μ₂ = μ₃ = ... = μₖ (All group means are equal, tenure doesn't matter) H₁: At least one group mean differs (Tenure matters) Decision: If F sig < 0.05 → Reject H₀

Key Output — ANOVA Table

SourceWhat It Is
Between Groups (Regression)Variation due to the IV (treatment effect)
Within Groups (Error/Residual)Variation within each group (random error)
F = MSB / MSWRatio of between to within group variance. Larger F → more likely significant
Sig.p-value. If < 0.05 → at least one group differs
Post-Hoc Tests: ANOVA only tells you that groups differ — NOT which ones. Use Tukey's HSD or Bonferroni post-hoc tests to find which specific group pairs are different.

Assumptions

  • Normality within each group (use Levene's test for homogeneity)
  • Independence of observations
  • DV is interval/ratio scale
SPSS Path: Analyze → Compare Means → One-Way ANOVA → Post Hoc → Tukey

Two-Way / N-Way ANOVA (Factorial ANOVA)

Purpose: Test the effect of TWO OR MORE independent variables (and their interaction) on one DV simultaneously. Also called Between-Subjects ANOVA or Factorial ANOVA.

When to Use

Factorial experimental design with 2+ IVs. E.g., AUGTARGET (onbody/ontoenv) AND mediatype (AR/NonAR) → WTP. Detergent type AND water temperature → Whiteness.

Hypothesis — Three Sets (for 2-Way ANOVA)

1. MAIN EFFECT of IV1: H₀: AUGTARGET has no effect on WTPayprimium H₁: AUGTARGET significantly affects WTPayprimium 2. MAIN EFFECT of IV2: H₀: Mediatype has no effect on WTPayprimium H₁: Mediatype significantly affects WTPayprimium 3. INTERACTION EFFECT (IV1 × IV2): H₀: The interaction of AUGTARGET and mediatype has no effect on WTPayprimium H₁: The interaction significantly affects WTPayprimium

Key Output — Tests of Between-Subjects Effects

RowWhat to Check
Corrected ModelOverall model fit. If sig < 0.05, the model is significant.
IV1 (e.g., AUGTARGET)Main effect of first IV. F value & Sig. p < 0.05 → significant.
IV2 (e.g., mediatype)Main effect of second IV.
IV1 * IV2 (Interaction)Interaction effect. p < 0.05 → the effect of one IV depends on the level of the other IV.
R Squared% variance in DV explained by all IVs combined.
Interaction Effect: When significant, it means the effect of IV1 on DV is DIFFERENT depending on the level of IV2. Plot an interaction plot (line graph) to visualize. If lines are parallel → no interaction. If lines cross or diverge → interaction exists.
SPSS Path: Analyze → General Linear Model → Univariate → Fixed Factors → Plots

ANCOVA — Analysis of Covariance

Purpose: Like ANOVA, but also statistically controls for the effect of one or more continuous covariates. Removes noise from the analysis to get purer IV effects.

When to Use

When you suspect a continuous variable (covariate) is influencing your DV and you want to "remove" its effect before comparing groups. E.g., Compare usefulness of App vs Website while controlling for prior tech experience.

Hypothesis

H₀: After controlling for [covariate], group means on DV are equal H₁: After controlling for [covariate], group means differ significantly Same ANOVA table structure, but covariate appears as an extra row. If covariate Sig < 0.05 → it was indeed related to DV (good to control)

Key Concepts

  • Covariate: Continuous variable whose effect is removed (e.g., age, income, prior experience)
  • Adjusted Means: Group means after removing covariate effect — these are what you compare
  • Assumption: Homogeneity of regression slopes (covariate relationship must be same across groups)
SPSS Path: Analyze → General Linear Model → Univariate → Fixed Factors + Covariate(s)

Correlation (Pearson's r)

Purpose: Measure the strength and direction of the linear relationship between two continuous variables. Does NOT imply causation.

When to Use

Both variables are continuous (interval/ratio). E.g., Is Holacracy satisfaction related to Motivation? What is the relationship between HOL_IMP, STAY, REC, MOT?

Hypothesis

H₀: ρ = 0 (No linear relationship between Variable A and Variable B) H₁: ρ ≠ 0 (There is a significant linear relationship) Decision: If p (Sig. 1-tailed or 2-tailed) < 0.05 → Reject H₀

Regression (Simple / Multiple)

Purpose: Predict the value of a DV from one or more IVs. Quantifies the direction and magnitude of effect. Establishes a predictive equation.

When to Use

You want to predict or explain a continuous DV using one or more IVs. E.g., Does Holacracy satisfaction predict Motivation? Does HOL_IMP predict STAY?

Hypothesis

H₀: β = 0 (IV has no significant impact on DV / slope = 0) H₁: β ≠ 0 (IV has a significant impact on DV) Decision: If ANOVA F sig < 0.05 → Model is significant If Coefficients t sig < 0.05 → That specific IV is significant

Factor Analysis

Purpose: Reduce a large number of correlated variables into a smaller set of underlying factors or dimensions. An interdependence technique — no IV/DV distinction.

When to Use

  • You have many variables and want to simplify them
  • You want to identify underlying constructs (e.g., 7 lifestyle statements → 3 personality factors)
  • Preparing data for regression by creating composite variables
  • Questionnaire validation

Prerequisites Before Running Factor Analysis

  1. Sample Size: Minimum 5-10 observations per variable, preferably N ≥ 200
  2. Interval/Ratio Data: Variables should be continuous (Likert treated as interval)
  3. Correlations must exist: Variables should be correlated with each other
  4. KMO > 0.5: Kaiser-Meyer-Olkin measure of sampling adequacy must be acceptable
  5. Bartlett's Test significant: p < 0.05 confirms correlations are not all zero

Discriminant Analysis

Purpose: Classify observations into pre-defined groups based on a set of predictor variables. "Can we predict which group a case belongs to based on these variables?"

When to Use

  • DV is categorical (group membership: Developed/Underdeveloped country, Customer/Non-customer)
  • IVs are continuous (discriminating variables: GNI, Health expenditure, Birth rate)
  • Goal: find the linear combination of IVs that best separates the groups

Reading Discriminant Analysis Output

Eigenvalue
Larger = better discrimination. % variance = how much this function explains.
Canonical Correlation
Correlation between discriminant scores and group. Range 0–1. Closer to 1 = better separation. Example: 0.862 = strong discrimination
Wilks' Lambda
Ranges 0–1. Closer to 0 = better discrimination. If Sig. < 0.05 → function significantly separates groups. Example: λ=0.258, p=0.000 ✓
Structure Matrix
Correlation of each variable with the discriminant function. Tells you which variables are most important for discrimination. GNI (.876) > Health exp (.720) > Birth rate (-.544)
Classification Table
% of cases correctly classified. Overall accuracy = (correctly classified / total) × 100. Example: 26+32 out of 60 = 96.7% accuracy

Adidas Brand Perception Study — Independent T-Test, Two-Way ANOVA, Research Design for Zara
Q1 Analysis of Adidas Brand Perception Study — App vs Website Usefulness 11 Marks ▼
Part (a) — 1 Mark | Identify IV and DV
Answer
Independent Variable (IV): Platform Type — App vs Website (categorical, 2 groups)
Dependent Variable (DV): Usefulness Score — measured on a 5-point Likert scale (treated as interval/continuous)
Part (b) — 1 Mark | State the Hypothesis
Answer
H₀: There is no significant difference in the perceived usefulness of the Adidas App and Website (μ_App = μ_Website)
H₁: There is a significant difference in the perceived usefulness of the Adidas App and Website (μ_App ≠ μ_Website) — Two-tailed
Part (c) — 1 Mark | Specify which test and why
Answer
Test Used: Independent Samples T-Test

Why: (1) The IV is categorical with exactly 2 independent groups (App users vs Website users — different respondents). (2) The DV (Usefulness) is measured on a 5-point Likert scale, treated as interval/continuous. (3) The two groups are independent — different people used the App vs the Website. These three conditions satisfy the requirements for an Independent Samples T-Test.
Part (d) — 2 Marks | Suggest control variables
Answer
The following variables should be controlled to ensure the experiment's internal validity:

1. Tech-savviness / Digital literacy — More tech-literate users may rate apps higher regardless of actual quality
2. Frequency of use — Users who use the app/website more often may rate it differently due to familiarity bias
3. Device type — App experience varies on Android vs iOS; website experience varies by browser
4. Prior brand experience / loyalty — Existing Adidas fans may rate all platforms higher due to brand sentiment
5. Age / demographic — Younger users may be more comfortable with apps; older users with websites
Part (e) — 2 Marks | Interpret the results
Answer
Step 1 — Group Statistics: Website (M=4.23, SD=0.91, N=175) vs App (M=3.06, SD=0.76, N=177). Website mean is visibly higher.

Step 2 — Levene's Test: F = 0.609, Sig = 0.436 > 0.05 → Variances are equal. We use the "Equal variances assumed" row.

Step 3 — T-Test Result: t = -13.527, df = 350, Sig. (2-tailed) = 0.013 < 0.05 → Reject H₀

Step 4 — Mean Difference: -1.6536 (App rated 1.65 points lower). 95% CI: [-1.8655, -0.4784] — does not include zero → confirms significant difference.

Conclusion: There is a statistically significant difference in perceived usefulness between the Adidas App and Website. The Website is significantly more useful than the App (p = 0.013 < 0.05).
Part (f) — 4 Marks | Recommendations to Adidas
Answer
Based on the finding that the Website (M=4.23) is rated significantly more useful than the App (M=3.06):

1. Improve App UX: Adidas should invest in app interface redesign — simplify navigation, reduce load times, and improve product search/filter functionality. The 1.65-point gap in usefulness is substantial and commercially risky given the growing mobile-first consumer base.

2. Benchmark App Against Website: Conduct a feature-parity audit — identify what the Website does well (e.g., detailed product info, smooth checkout) and replicate it on the App.

3. AR/Interactive Features: If the App has AR features, ensure they work smoothly — a buggy AR experience can disproportionately hurt usefulness ratings.

4. User Feedback Loop: Add in-app feedback prompts after purchase/browsing sessions to continuously capture usefulness gaps.

5. Focus on Brand Perception via Website: Since the Website already has high usefulness (4.23/5), Adidas should continue leveraging it for brand storytelling, lookbooks, and campaigns while the App is being improved.
Q2 Analysis for Willingness to Pay — AR Augmentation Study (Two-Way ANOVA) 11 Marks ▼
Part (a) — 1 Mark | Identify IV and DV
Answer
Independent Variables (IVs) — 2 IVs:
1. AUGTARGET — Whether augmentation is on-body (onbody) or on-environment (ontoenv) — Categorical, 2 levels
2. Mediatype — Whether media uses Augmented Reality (AR) or Non-AR — Categorical, 2 levels

Dependent Variable (DV): WTPayPrimium — Willingness to Pay Premium — Continuous
Part (b) — 1 Mark | State the Hypothesis
Answer — Three Sets of Hypotheses
H₀₁: AUGTARGET has no significant effect on Willingness to Pay Premium
H₁₁: AUGTARGET has a significant effect on WTP

H₀₂: Mediatype (AR vs NonAR) has no significant effect on WTP
H₁₂: Mediatype has a significant effect on WTP

H₀₃: The interaction between AUGTARGET and Mediatype has no significant effect on WTP
H₁₃: The interaction significantly affects WTP
Part (c) — 1 Mark | Test Used and Why
Answer
Test Used: Two-Way ANOVA (Factorial ANOVA / Between-Subjects ANOVA)

Why: There are TWO categorical independent variables (AUGTARGET and Mediatype), each with 2 levels, and one continuous dependent variable (WTPayPrimium). This constitutes a 2×2 factorial design. Q3 Tests, Hypotheses for Four Sub-Parts 10 Marks (2.5 each) ▼
Part (a) | Do males and females differ in Hol_Imp satisfaction?
Test: Independent Samples T-Test
H₀: Males and females do not differ in their opinion of satisfaction with Holacracy (μ_Male = μ_Female)
H₁: Males and females differ significantly in their satisfaction with Holacracy (μ_Male ≠ μ_Female)

Why Independent T-Test: IV = Gender (categorical, 2 groups: Male/Female). DV = HOL_IMP (Likert, treated as interval/continuous). Two different groups of people (not the same person measured twice). Exactly 2 groups → t-test (not ANOVA).
Part (b) | Does tenure matter in Hol_Imp satisfaction?
Test: One-Way ANOVA
H₀: Tenure does not significantly affect employee satisfaction with Holacracy (μ₁ = μ₂ = ... = μ₈)
H₁: At least one tenure group differs significantly in satisfaction with Holacracy

Why One-Way ANOVA: IV = Tenure (categorical, 8 groups: <3 months through 15+ years). DV = HOL_IMP (continuous). More than 2 groups → use ANOVA not t-test. One IV → One-Way ANOVA. Follow with Tukey post-hoc to identify which tenure groups differ.
Part (c) | Is Hol_Imp satisfaction greater than 3?
Test: One Sample T-Test
H₀: Mean satisfaction with Holacracy is ≤ 3 (HOL_IMP ≤ 3 — not greater than neutral)
H₁: Mean satisfaction with Holacracy is > 3 (HOL_IMP > 3) — One-tailed test

Why One Sample T-Test: We are comparing the mean of ONE sample to a known/specified test value (3 = midpoint of Likert scale). There is only one group, no second group to compare against. The question asks if the score is "greater than" — directional, so one-tailed. Test Value = 3 entered in SPSS.
Part (d) | Does Holacracy satisfaction predict Stay intentions?
Test: Simple Linear Regression
H₀: Holacracy satisfaction (HOL_IMP) has no significant impact on stay intentions (STAY) — β = 0
H₁: Holacracy satisfaction significantly predicts stay intentions — β ≠ 0

Why Regression: The question asks whether HOL_IMP predicts STAY — this is a cause-effect directional relationship requiring regression. IV = HOL_IMP (continuous), DV = STAY (continuous). The correlation table (r = 0.414) suggests a relationship exists — regression quantifies the predictive equation and explains % variance.

Note: The handwritten answer sheet says "Paired t-test" for this — that is incorrect. Paired t-test compares means of the same variable at two time points. To test prediction/causality between two continuous variables, regression is the correct choice.

Q3 Purpose of Factor Analysis + Conditions Required 5 Marks ▼
Answer
Purpose of Factor Analysis (2 marks):
1. Data Reduction: Reduce a large number of variables into a smaller, manageable set of factors without significant loss of information.
2. Identify Underlying Constructs: Uncover latent dimensions or constructs that explain the correlations among observed variables.
3. No Dependent Variable: Unlike regression, factor analysis is an interdependence technique — it examines the entire variable set without distinguishing IV from DV.
4. Questionnaire Validation: Used to confirm whether survey items measure what they claim to measure (construct validity).

Conditions Required Before Factor Analysis (3 marks):
1. KMO > 0.5: Kaiser-Meyer-Olkin measure must be above 0.5. Values ≥ 0.7 are good. If KMO < 0.5, factor analysis should not be performed.
2. Bartlett's Test of Sphericity significant: p < 0.05. Confirms that the correlation matrix is not an identity matrix — i.e., variables are correlated with each other.
3. Sample Size: Minimum 5 observations per variable; ideally N ≥ 100–200. Very small samples yield unreliable factor solutions.
4. Interval/Ratio Data: Variables should be continuous. Likert scale items (at least 5 points) are typically treated as interval.
5. Absence of Multicollinearity: Variables should be correlated but not perfectly correlated (r should not be close to 1.0 for any pair).
