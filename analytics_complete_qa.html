Statistics Fundamentals
Distributions · Probability · Descriptive Stats
Q 01 In a right-skewed distribution, which statement is true about mean and median?
Mean < MedianMean = MedianMean > Median ✓Mode > Mean
✓
Mean > Median

In a right-skewed (positively skewed) distribution, there's a long tail stretching to the right. A few very large values pull the mean upward more than they affect the median. The median stays closer to the bulk of the data. Remember the order: Mode < Median < Mean for right skew.

Q 02 Standard normal distribution has:
Mean=1, SD=0Mean=0, SD=1 ✓Mean=0, SD=0Mean=1, SD=1
✓
Mean = 0, SD = 1

The Standard Normal (Z-distribution) is always centered at 0 with standard deviation 1. Any normal distribution can be converted to it using Z = (X − μ) / σ. This is the foundation of Z-tests, Z-tables, and confidence intervals.

Q 03 Which distribution is appropriate for the number of customer arrivals per hour?
NormalBinomialPoisson ✓Uniform
✓
Poisson

Poisson models the count of independent events occurring in a fixed interval of time or space. Classic examples: customers/hour, calls/day, website clicks/minute. Its defining property: Mean = Variance = λ. Binomial is for a fixed number of trials, Normal is for continuous data.

Q 04 Mean of a Poisson distribution is 3. What is the variance?
93 ✓√31/3
✓
3

Poisson's unique property: Mean = Variance = λ. If mean = 3, variance = 3. SD = √3 ≈ 1.73. This single parameter λ defines both the center and spread of the distribution — unlike most other distributions which need separate parameters for each.

Q 05 Population mean = 100, SD = 20, sample size = 100. What is the Standard Error?
202 ✓0.2200
✓
2

Standard Error = σ / √n = 20 / √100 = 20 / 10 = 2. SE measures the spread of sample means around the true population mean. It decreases as sample size grows, meaning larger samples give more precise estimates.

Q 06 Mean = 50. Each observation increases by 5. What is the new mean?
5055 ✓50045
✓
55

When a constant is added to every data point, the mean shifts by that same constant. If every value goes up by 5, the average also goes up by 5. Mean(X + c) = Mean(X) + c. However, variance stays the same because the spread between points doesn't change — only the center shifts.

Q 07 A and B are mutually exclusive. P(A) = 0.4, P(B) = 0.3. What is P(A ∪ B)?
0.120.7 ✓0.50.1
✓
0.7

For mutually exclusive events (they can't happen together): P(A ∪ B) = P(A) + P(B) = 0.4 + 0.3 = 0.7. There's no overlap to subtract. If they weren't mutually exclusive, you'd subtract P(A ∩ B) using the general addition rule. 0.12 would be P(A) × P(B) — that's for independent events.

Q 08 Probability of getting a number greater than 4 on a die:
1/62/6 ✓3/64/6
✓
2/6 (= 1/3)

On a 6-sided die, the outcomes greater than 4 are {5, 6} — exactly 2 outcomes out of 6. So P(X > 4) = 2/6 = 1/3 ≈ 0.33. A simple but important concept: always count favourable outcomes and divide by total outcomes for equally likely events.

Q 09 Central Limit Theorem is useful because it allows:
Small samples to be ignoredNormal approximation of sampling distribution ✓Exact population estimationElimination of bias
✓
Normal approximation of sampling distribution

The Central Limit Theorem (CLT) states: regardless of the original population's distribution, the sampling distribution of the sample mean becomes approximately normal for sufficiently large n (typically n ≥ 30). This is why so many statistical tests can assume normality — even when the underlying data isn't normal.

Q 10 Least appropriate measure of central tendency when data has extreme outliers:
Mean ✓MedianMode
✓
Mean

The mean sums all values, so a single extreme outlier (e.g., one billionaire in a room of 100 average people) can drag it far from the typical value. The median is the preferred measure when outliers are present — it's resistant to extreme values because it only cares about the middle rank. This is why median is used for income and house prices.

Hypothesis Testing
p-values · CI · ANOVA · Distributions
Q 11 Type I error occurs when:
True null acceptedFalse null rejectedTrue null rejected ✓False null accepted
✓
True null is rejected

Type I = False Positive. You reject H₀ even though it is actually true — you see an effect that doesn't exist. Type II (False Negative) is the opposite: failing to reject a false H₀. Easy way to remember: Type I error rate = α (your significance level). Raising α makes Type I errors more likely but reduces Type II errors.

Q 12 If p-value < α, the decision is to:
Accept H₀Reject H₀ ✓Increase sampleChange hypothesis
✓
Reject H₀

The p-value is the probability of seeing your results (or more extreme) if H₀ were true. If this probability is below your pre-set threshold α (usually 0.05), the evidence is strong enough to reject the null hypothesis. Think of α as your tolerance for being wrong — p < α means the result is statistically significant.

Q 13 If a regression coefficient is statistically insignificant (p > 0.05), we:
Accept alternativeConclude strong effectFail to reject null ✓Increase R²
✓
Fail to reject null

p > 0.05 means there is insufficient evidence to conclude the variable has a real effect. We do not "accept" H₀ — we simply fail to reject it. There's an important distinction: not rejecting is not the same as proving H₀ is true. It just means the data doesn't give enough signal to call the variable significant.

Q 14 A 95% confidence interval implies:
Parameter lies inside with 95% probability95% samples contain the parameterLong-run 95% intervals contain the true parameter ✓Sample mean is correct
✓
Long-run 95% intervals contain the true parameter

This is the most misunderstood concept in stats. The true parameter is a fixed, unknown value — it either is or isn't in your interval. The correct frequentist interpretation: if you repeated sampling 100 times, about 95 of those 100 different intervals would contain the true value. It's a statement about the long-run reliability of the method, not about any single interval.

Q 15 Which factor reduces the margin of error?
Higher confidenceSmaller sampleLarger sample ✓Larger variance
✓
Larger sample

Formula: MoE = Z × (σ / √n). A larger n increases √n, shrinking the fraction — so MoE gets smaller and your estimate becomes more precise. Higher confidence (larger Z) increases MoE. Larger variance (σ) also increases MoE. Only increasing sample size directly reduces margin of error.

Q 16 Which test checks association between two categorical variables?
t-testZ-testChi-square ✓ANOVA
✓
Chi-square

The Chi-square test of independence checks if two categorical variables are associated or independent. Example: "Is gender related to product preference?" t-test and Z-test compare numerical means. ANOVA compares means across 3+ groups. Chi-square works on frequency counts in a contingency table — it compares observed vs expected counts.

Q 17 A company wants to compare average sales across 4 regions. Which test is suitable?
t-testChi-squareANOVA ✓Regression
✓
ANOVA

Rule: comparing means of 3 or more groups → ANOVA. The t-test is strictly for 2 groups. ANOVA (Analysis of Variance) tests whether at least one group mean is significantly different from the others. Chi-square is for categorical counts. The key trigger: "4 regions" → more than 2 → ANOVA every time.

Q 18 Population variance is unknown and sample size is small. Which distribution to use?
Zt ✓Chi-squareF
✓
t-distribution

Z-distribution requires knowing the true population SD (σ), which is rarely available. When σ is unknown and n is small (typically <30), use the t-distribution — it has heavier tails than Z to account for extra uncertainty. As n increases, t approaches Z. The t-distribution is parameterized by degrees of freedom = n − 1.

Regression Analysis
OLS · Logistic · Coefficients · Assumptions
Q 19 R² = 0.8 indicates:
Poor model80% variance explained ✓80% errorHigh bias
✓
80% of variance is explained by the model

R² (coefficient of determination) measures the proportion of total variance in Y that is explained by the model's predictors. R² = 0.8 means 80% of the variation in the outcome is explained by the features — the remaining 20% is unexplained. R² = 1 is a perfect fit; R² = 0 means the model explains nothing more than just predicting the mean.

Q 20 Adjusted R² is preferred over R² because it:
Always largerPenalizes unnecessary variables ✓Ignores sample sizeEquals correlation
✓
Penalizes unnecessary variables

R² always increases (or stays same) when you add more features — even useless ones. This makes it a bad metric for model comparison. Adjusted R² corrects for this by penalizing for the number of predictors added. It only increases if the new variable improves the model more than chance alone would. Use Adjusted R² whenever comparing models with different numbers of features.

Q 21 Multicollinearity refers to:
Correlated errorsCorrelated predictors ✓Non-linear dataOutliers
✓
Correlated predictors

Multicollinearity occurs when two or more independent variables are highly correlated with each other. Example: including both "years of experience" and "age" in the same model. The problem: the model can't isolate each variable's individual effect — coefficients become unstable and unreliable. The overall R² may still look fine. Detected using VIF (Variance Inflation Factor); VIF > 10 is a warning sign.

Q 22 A pricing model shows discount coefficient = +2.5 (positive). But business says higher discount reduces revenue. What is likely wrong?
Scaling issueReverse causalityMulticollinearity or confounding ✓Data imbalance
✓
Multicollinearity or confounding

The coefficient sign is completely counter-intuitive. A hidden confounding variable is distorting the model. For example: premium products may receive higher discounts AND generate high revenue — making discount appear positively linked to revenue. The real driver is product type, not discount. Multicollinearity between predictors can similarly produce wrong signs. This is why domain knowledge must always validate model outputs.

Q 23 Model predictions shift significantly after adding one extreme data point. Regression is sensitive to:
Missing dataOutliers ✓ScalingRegularization
✓
Outliers

OLS regression minimizes the sum of squared errors. Squaring means extreme errors get disproportionately large weight — one outlier can pull the regression line dramatically. These influential points are called leverage points. Solutions: detect outliers using Cook's Distance or residual plots, apply log transformations, or use robust regression methods like Huber regression which are less sensitive.

Q 24 If logistic regression coefficient = 0, it means:
Perfect predictionNo impact on log-odds ✓High probabilityMulticollinearity
✓
No impact on log-odds

Logistic regression models: log-odds = β₀ + β₁x₁ + .... If a coefficient β = 0, that feature's term disappears entirely from the equation — it contributes zero effect on the predicted log-odds. The feature is statistically irrelevant. Odds ratio for that feature = e⁰ = 1, meaning no change in odds regardless of the feature's value.

Q 25 Correlation between X and Y = 0.92. Business concludes X causes Y. This assumption is:
Statistically correctRisky causal inference ✓Always validRegression rule
✓
Risky causal inference

Correlation ≠ Causation — one of the most important principles in analytics. High correlation only tells you the two variables move together. A confounding variable could be driving both, or the direction could be reversed (Y causes X), or the relationship could be coincidental. True causation requires controlled experiments (RCTs), natural experiments, or causal inference methods like instrumental variables or difference-in-differences.

Q 26 Correlation between X and Y is 0.8. What is the correlation between Y and X?
−0.80.8 ✓01
✓
0.8

Correlation is symmetric: r(X, Y) = r(Y, X) by definition. The Pearson formula is Cov(X,Y) / (σx × σy) — swapping X and Y gives the same result since Cov(X,Y) = Cov(Y,X). The strength of the linear relationship between two variables is the same regardless of which variable you call X and which you call Y.

Machine Learning Concepts
Bias-Variance · Regularization · Classification · Model Evaluation
Q 27 Both training error and test error are high. What is this called?
OverfittingUnderfitting ✓Data leakagePerfect bias
✓
Underfitting (High Bias)

The error pattern tells you everything: Underfitting = both errors high → model too simple, hasn't learned even the training data. Overfitting = training error low, test error high → model memorized training noise but fails to generalize. When both errors are high simultaneously, the model is fundamentally too simple. Fix: use more complex model, add features, reduce regularization.

Q 28 You add 15 new features and training error drops, but test error increases. Best interpretation?
Better biasHigher variance (overfitting) ✓Reduced complexityPerfect fit
✓
Higher variance — Overfitting

Low training error + high test error = classic overfitting. Adding many features gives the model more ways to memorize training-specific noise. The model learns patterns that don't generalize to new data. This is high variance. Fix: remove irrelevant features, use regularization (L1/L2), use cross-validation, or get more training data.

Q 29 Polynomial features improve training error but not test error. This indicates:
High biasHigh variance (overfitting) ✓Better generalizationMulticollinearity solved
✓
High variance — Overfitting

Same signature: training improves, test doesn't follow. Polynomial features increase model complexity by creating new feature combinations (x², x³, x₁x₂...). If these additions help only on training data, the model is fitting the specific quirks of training data rather than the true underlying pattern. This is overfitting = high variance.

Q 30 Training R² = 0.91 but Test R² = 0.52. Why the big performance drop?
Model too simpleData leakageOverfitting to historical noise ✓Wrong loss function
✓
Overfitting

A large gap between train and test performance is the clearest signal of overfitting. The model learned the training data almost perfectly (R²=0.91) but only explains 52% of variance in new data. It memorized noise and specific patterns in the training set that don't exist in the real world. The larger the train-test gap, the worse the overfitting.

Q 31 You regularize a model heavily. What is the result?
Lower biasHigher varianceSimpler model ✓More overfitting
✓
Simpler model

Regularization (L1 = Lasso, L2 = Ridge) adds a penalty for large coefficients, forcing the model to stay simple. Heavy regularization shrinks many coefficients toward zero — reducing complexity, increasing bias, and decreasing variance. It is the solution to overfitting, not a cause. More regularization → simpler model → higher bias, lower variance.

Q 32 A model works well historically but fails after 1 year. Likely reason?
Data leakageConcept drift ✓MulticollinearityUnderfitting
✓
Concept drift

Concept drift happens when the real-world relationship between inputs and outcome changes over time — consumer behaviour shifts, markets evolve, new patterns emerge. The model was trained on old, no-longer-valid patterns. Data leakage causes failure immediately, not after a year. Multicollinearity affects coefficient interpretation but not time-based performance decay. This is a core model monitoring and MLOps problem.

Q 33 Cross-validation mainly reduces the risk of:
Overfitting ✓UnderfittingScaling issuesMissing values
✓
Overfitting

K-fold cross-validation splits data into k folds, training on k-1 and testing on 1 repeatedly. This ensures the model is evaluated on data it has never trained on, exposing any tendency to overfit. It provides a more reliable estimate of true out-of-sample performance compared to a single train-test split. It doesn't fix overfitting but helps you detect it and choose better models/hyperparameters.

Q 34 Increasing the decision threshold increases:
RecallFalse negatives ✓True positivesSensitivity
✓
False negatives

A higher threshold (e.g., 0.5 → 0.8) means the model only predicts "positive" when very confident. This makes it more conservative — it misses more actual positives → more False Negatives, less Recall. Precision goes up (fewer false alarms). This is the Precision-Recall tradeoff: you tune the threshold based on whether false positives or false negatives are costlier in your business context.

Q 35 In imbalanced data (e.g., 99% negative class), the most misleading metric is:
RecallF1-scoreAccuracy ✓Precision
✓
Accuracy

A model that predicts "negative" for everything achieves 99% accuracy on a dataset that's 99% negative — yet it's completely useless. Accuracy is misleading when classes are imbalanced. Prefer Precision, Recall, F1-score, or AUC-ROC for imbalanced datasets. These metrics specifically measure how well the model handles the minority class, which is usually what you care about (fraud, disease, churn).

Q 36 In credit scoring, approving a risky customer is very costly. Which error is worse?
False negativeFalse positive ✓True negativeTrue positive
✓
False positive

Define: Positive = predicted creditworthy (approved). A False Positive = predicted safe, but actually risky → loan approved → customer defaults → direct financial loss. A False Negative = predicted risky, but actually safe → loan rejected → you lose a potential customer, but no loan loss. Since approving risky customers is "costly," the costlier error is False Positive. Banks set high thresholds precisely to reduce false positives.

Q 37 Distance-based methods (KNN, K-Means) are sensitive to:
DistributionScaling ✓R²Loss function
✓
Scaling

Distance calculations are dominated by features with larger numeric ranges. If income (₹20,000–₹5,00,000) and age (20–60) are both features, income will dominate the distance measure purely due to scale. Always normalize or standardize before using KNN, K-Means, SVM, or PCA. Z-score standardization: subtract mean, divide by SD. Min-max normalization: scale to 0–1.

Clustering & Segmentation
K-Means · DBSCAN · Hierarchical · Silhouette
Q 38 Segmentation is used mainly for:
Supervised predictionCustomer grouping ✓Regression modelingProbability estimation
✓
Customer grouping

Segmentation is unsupervised learning — no labelled outcome to predict. The goal is to discover natural groups of similar customers based on behaviour, demographics, or purchase patterns. This enables targeted marketing, personalized offers, and tailored strategy per segment. It does not predict an outcome variable; that's what classification or regression is for.

Q 39 If K (number of clusters) in K-Means is chosen too large, what happens?
Over-segmentation ✓Under-segmentationData leakageReduced variance
✓
Over-segmentation

Too large K = algorithm creates more clusters than naturally exist → it splits groups that belong together into tiny, meaningless pieces. Too small K = under-segmentation (merges groups that should be separate). The Elbow Method and Silhouette Score are used to find the optimal K by balancing compactness within clusters and separation between them.

Q 40 K-Means gives unstable (different) clusters every time you rerun it. Why?
Random initialization ✓UnderfittingRegression issueScaling irrelevant
✓
Random initialization

K-Means starts by randomly placing K centroids. Different starting positions lead the algorithm to converge at different local minima — resulting in different cluster assignments on every run. This is a well-known limitation. Solutions: K-Means++ (smarter initialization), running multiple times and picking the best result, or setting a random seed for reproducibility.

Q 41 Adding irrelevant features in clustering leads to:
Better clustersNoise in segmentation ✓Reduced varianceBetter silhouette
✓
Noise in segmentation

Every feature contributes to distance calculations in clustering. Irrelevant features inject meaningless noise into those distances, blurring natural group boundaries. The algorithm treats these random signals as real patterns. This is part of the curse of dimensionality — adding more features doesn't mean better clusters; irrelevant ones actively distort them. Always do feature selection before clustering.

Q 42 Customer income dominates clustering because of its large scale. How to fix?
Remove incomeStandardize features ✓Add more dataIncrease K
✓
Standardize features

Income (₹20k–₹5L) vs number of purchases (1–50): income dominates distance purely because of its numeric scale — not because it's more important. Standardizing (Z-score: subtract mean, divide by SD) brings all features to mean=0, SD=1, giving them equal footing. Removing income entirely wastes valuable data. Standardize, don't eliminate.

Q 43 If silhouette score is low, it indicates:
Clusters well-separatedPoor cluster separation ✓Perfect segmentationOverfitting
✓
Poor cluster separation

Silhouette Score ranges from −1 to +1. For each point, it compares how similar the point is to its own cluster vs other clusters. High score (near +1) = tight, well-separated clusters. Low score (near 0 or negative) = clusters overlap or points are misassigned. It's the primary unsupervised metric for cluster quality when ground truth labels are unavailable.

Q 44 If clusters overlap heavily, it indicates:
Natural segmentation is weak ✓Perfect segmentationHigh biasModel stable
✓
Natural segmentation is weak

Heavy overlap means the data does not naturally separate into distinct groups — there are no clear boundaries between segments. This is a data problem, not necessarily an algorithm problem. Possible causes: wrong features chosen, too many clusters, or the data genuinely doesn't have strong natural groupings. Low silhouette scores will confirm this. Consider dimensionality reduction (PCA) to find more meaningful structure.

Q 45 DBSCAN is preferred when:
Clusters are sphericalNoise/outliers are present ✓K is knownLinear relation exists
✓
Noise is present in data

DBSCAN (Density-Based Spatial Clustering) identifies clusters as dense regions separated by sparse regions. Its key advantages: it can find clusters of arbitrary shape (not just spherical like K-Means), and it explicitly handles outliers/noise by labelling low-density points as noise (class -1). You don't need to specify K upfront. Disadvantage: struggles with varying density clusters.

Q 46 Hierarchical clustering is most useful when:
Tree-like segmentation is needed ✓Very large dataset onlyRegression neededBinary classification
✓
Tree-like (hierarchical) segmentation is needed

Hierarchical clustering produces a dendrogram — a tree diagram showing how clusters merge or split at different levels. This is uniquely useful when you want to explore data structure at multiple granularities (e.g., broad macro-segments → narrow micro-segments) without fixing K upfront. Downside: computationally expensive (O(n²) or worse), making it impractical for very large datasets.

Model Diagnostics & Residuals
Residuals · Heteroscedasticity · Error Analysis
Q 47 Residual is defined as:
Actual − Predicted ✓Predicted − ActualMean − MedianError variance
✓
Actual − Predicted

A residual = the difference between what actually happened and what your model predicted: e = Y_actual − Ŷ_predicted. A positive residual means the model underestimated; negative means overestimated. Residual analysis (residual plots, normality of residuals, etc.) is the primary way to check whether regression assumptions are satisfied and diagnose model problems.

Q 48 Residual plot shows a funnel shape — variance increases with predicted values. What should the analyst suspect?
MulticollinearityHeteroscedasticity ✓UnderfittingData imbalance
✓
Heteroscedasticity

Regression assumes homoscedasticity — constant variance of residuals. A funnel shape in the residual plot is the classic visual signature of heteroscedasticity: errors are small at low fitted values and grow larger at higher ones (or vice versa). This violates an OLS assumption, making standard errors unreliable and t-tests invalid. Fixes: log-transform the target variable, or use Weighted Least Squares (WLS).
